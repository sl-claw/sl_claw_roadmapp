Рабочее место за 10 минут: VS Code + Claude Code + GitHub

Это самый первый урок. Здесь мы соберём рабочее место и подключим помощника Claude Code. Ничего технического знать не нужно — просто повторяй за инструкцией. В конце ты сможешь давать задачи обычными словами, а Claude будет всё делать сам.

Что понадобится (приготовь заранее)

1. Аккаунт Claude — подписка Pro или Max.
2. Аккаунт GitHub — бесплатный.
3. Ссылка на твой проект — мы её тебе дали.

🎬 Видео урока

Ниже — пошаговая шпаргалка. Та же инструкция текстом, чтобы повторять на паузе.

Шаг 1. Установить VS Code

VS Code — бесплатный редактор от Microsoft, навсегда без подписки.

  1. Открой code.visualstudio.com
  2. Нажми большую кнопку Download (сайт сам определит твой компьютер)
  3. Mac: открой скачанный файл → перетащи иконку VS Code в папку Applications.
    Windows: запусти установщик → жми «Далее» (всё по умолчанию)
  4. Запусти VS Code
Проверь версию

Меню Help → About — нужна версия 1.98.0 или выше. Если ниже — обнови с того же сайта.

Шаг 2. Установить Claude Code

Claude Code — это помощник прямо внутри VS Code. Ставим как расширение.

  1. Открой Расширения: Cmd/Ctrl+Shift+X
  2. В поиске набери Claude Code
  3. Выбери официальное расширение от Anthropic → Install
  4. Подожди 10–15 секунд. Не появилось — перезапусти VS Code
Почему расширение, а не терминал

Расширение приносит всё с собой — Node.js ставить не нужно, а изменения видно наглядно (слева как было, справа как стало).

Шаг 3. Войти в аккаунт

  1. В правом верхнем углу нажми иконку-искру (⚡). Не видишь — сначала открой любой файл. Можно ещё нажать ✱ Claude Code в правом нижнем углу
  2. Нажми Sign In → откроется браузер
  3. Войди по подписке Claude Pro / Max
  4. Вернись в VS Code — он сам поймёт, что ты вошёл
Без API-ключей

Никакие ключи вводить не нужно — достаточно обычного входа по подписке.

Шаг 4. Подключить GitHub и открыть проект

  1. Напиши Claude в окошко: «Склонируй мой проект» и вставь ссылку, которую мы дали
  2. VS Code спросит, куда сохранить — выбери папку
  3. Один раз представься системе. Открой терминал внутри VS Code (Cmd/Ctrl+`) и вставь две строки (подставь свои данные):
git config user.email "твоя-почта@example.com"
git config user.name "Твоё Имя"

Теперь, когда Claude что-то меняет, он показывает изменения и спрашивает «Применить?». Смотришь → жмёшь галочку. Он сам сохранит и отправит на GitHub.

Режимы работы Claude

Внизу окошка ввода есть переключатель режима:

РежимЧто делаетКому
Plan (План)Сначала расскажет, что собирается сделать, ждёт твоё «ок»👍 новичку
Normal (Обычный)Спрашивает разрешение на каждое действиестандарт
Accept EditsСам применяет правки, но спрашивает на опасные командыкогда освоился
Bypass permissionsДелает всё без вопросовосознанно (см. ниже)

Совет: начни в режиме План. Когда привыкнешь — переключайся.

Режим «Bypass permissions» (без постоянных вопросов)

Если надоедает подтверждать каждый шаг — можно включить режим, где Claude не спрашивает.

  1. Настройки: Cmd/Ctrl+, → раздел Extensions → Claude Code (или в поиске набери claudeCode)
  2. Поставь галочку «Allow Dangerously Skip Permissions» — она добавит режим в переключатель
  3. Внизу окошка ввода выбери режим «Bypass permissions»
  4. (По желанию) чтобы он был по умолчанию — настройка Initial Permission Mode → bypassPermissions
Осторожно

В этом режиме Claude выполняет любую команду без подтверждения. Включай его только в своём проекте на своём сервере — изолированно. Не включай на компьютере с чужими/непроверенными проектами. Для обычной работы безопаснее Accept Edits или План.

Как разговаривать с Claude

Главное правило: говори простыми словами, как подрядчику.

❌ Плохо✅ Хорошо
«Исправь код»«Сделай кнопку «Получить смету» рядом с ценой»
«Добавь фичу»«Добавь форму: имя и телефон, после отправки — сообщение «Спасибо»»

Описал словами → посмотрел, что показал → нажал галочку ✓ или ✗ → не так, скажи «сделай крупнее». Можно сказать «отмени» — вернёт как было. Ошибиться почти невозможно.

Если что-то не так

  • Не видно иконку-искру — открой любой файл, она появится
  • «Not logged in» — нажми ✱ Claude Code внизу справа → Sign In
  • Долгая пауза после сообщения — это нормально, он думает, подожди 5–10 сек, не отправляй заново
  • «permission denied» при отправке на GitHub — вернись к двум строкам с почтой и именем (Шаг 4)
  • Cmd+Esc не работает (Mac) — Системные настройки → Клавиатура → Game Controllers → снять «Game Overlay»
Чек-пойнт — что должно быть готово
  • VS Code установлен (версия 1.98.0+)
  • Claude Code установлен
  • Выполнен вход (Pro/Max)
  • GitHub подключён (почта + имя заданы)
  • Проект открыт в VS Code
  • Понял режимы (План / Accept Edits / Bypass)
